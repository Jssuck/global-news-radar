# QC 指标定义与阈值

## 一级：规则清洗

| 指标 | 定义 | 阈值 | 口径 |
|---|---|---|---|
| 抽取成功率 | trafilatura 主链产出合格正文的文章占比 | ≥90%（M1 验收线） | 按源 7 天滚动；兜底链挽救的不计入主链 |
| 语言一致率 | 抽取语言 = 源声明语言 | ≥97% | fastText/lingua 双标签，不一致以 lingua 为准复核 |
| 精确去重拦截率 | URL 规范化+SHA256 命中的重复摄入占比 | ≥85% 重复被拦截 | 同源重复 URL 变体 |
| 近似去重精度 | MinHash/LSH 判定重复中人工确认比例 | ≥95%（抽检） | 跨语种不启用 MinHash（失效），用 embedding 聚类 |

## 二级：LLM 清洗

| 指标 | 定义 | 阈值 |
|---|---|---|
| JSON Schema 一次通过率 | LLM 输出首轮通过 Schema 校验占比 | ≥95% |
| 判负率（路由命中） | 被质量门判负而送 LLM 清洗的文章占比 | ≤20%（成本控制线） |
| 清洗破坏率 | LLM 清洗后正文信息丢失（人工抽检） | ≤1% |

## 三级：LLM 整理

| 指标 | 定义 | 阈值 |
|---|---|---|
| 摘要忠实度 | 抽检摘要无原文外事实 | ≥98% |
| 分类一致率 | 主题标签与人工判定一致 | ≥90% |
| 事件归并正确率 | 归并进同一事件的文章确属同一事件 | ≥92%，且来源 URL 列表完整率 100% |

## 成本观测指标

| 指标 | 说明 |
|---|---|
| 单篇 LLM 平均 token 成本 | 分模型记录，周报趋势 |
| prompt 缓存命中率 | 目标 ≥60% |
| Batch API 占比 | 非实时任务目标 ≥70% |

## 阈值治理

- 阈值为 M1/M2 验收口径的组成部分，修改 = 变更验收标准，必须走 milestone-gate-review
- 所有指标在源健康看板可视化，按「源 / 语种 / 级别」三维可钻取
